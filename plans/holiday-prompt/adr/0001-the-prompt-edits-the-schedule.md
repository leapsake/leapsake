# The prompt edits the occasion's schedule, not one year's copy of it

An occasion (a milestone, or an observance) has one schedule. Answering its prompt edits that
schedule, so this year's answer is also every later year's default. Ignoring the prompt repeats
what was chosen last time, and next year's prompt arrives pre-ticked from it. This replaces the
2026-10-01 design of a standing schedule plus per-year answers stamped with `occurrence_year`,
which made the prompt something other than what the owner meant: a yearly window into the same
setting the Person and Holiday screens edit.

## Consequences

- An ignored prompt no longer falls back to the kind's defaults (the day-of wish). It repeats your
  last answer, so a one-off sticks until the next prompt is answered.
- The prompt still offers the full offer set. A late year that trimmed an offer only changes what
  is pre-ticked, so it doesn't drop the offer for good.
- Milestones change first, as their own increment. The holiday prompt then reuses that.
