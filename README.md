# Leapsake

[![License](https://img.shields.io/github/license/leapsake/leapsake)](LICENSE)

A privacy-first people-management app — people, pets, tags, a relationship graph with derived
kinship, milestones, and contact methods. Data lives locally in SQLite; there is no cloud
dependency to use it.
